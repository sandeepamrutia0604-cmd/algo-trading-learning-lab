# Algo Trading Learning Lab

A practice lab for algorithmic trading, with paper money only: pick or write a rule for when to buy and sell, test it on
history, and see whether the result was skill or luck.

**[Download the latest Windows release](https://github.com/sandeepamrutia0604-cmd/algo-trading-learning-lab/releases/latest)**
(about 22 MB) · **[Website and four-minute tour](https://sandeepamrutia0604-cmd.github.io/algo-trading-learning-lab/)**

## Install

1. Download the zip from the latest release.
2. Right-click it, choose **Extract All** (don't run it from inside the zip).
3. Open the folder and double-click `AlgoTradingLab.exe`. A console window opens and so does your browser; leave the console window
   open while you use the app and close it to quit.

Windows SmartScreen may say "Windows protected your PC": the app isn't signed with a paid code-signing certificate. If you trust it,
click **More info**, then **Run anyway**. To check your download, compare
`Get-FileHash .\AlgoTradingLab-*-windows.zip -Algorithm SHA256` with `SHA256.txt` on the release page.

Your data lives in `%LOCALAPPDATA%\AlgoTradingLab`; updating or deleting the app folder never touches it.

## What this repository is

Only the website and the downloadable releases. The app has no account, no broker connection and sends nothing anywhere.
Educational use only: paper money, not investment advice. Free to use.
